# ShopOS 0.15.4 release candidate

This branch is a validation-only release candidate derived from `integration/shopos-master-consolidation`.

## Freeze policy
- Version is `0.15.4` from `image/VERSION`.
- No new features are to be added to this candidate.
- Only unambiguous release-blocking fixes and regression-test corrections are allowed.
- Product changes and temporary QEMU harness changes remain separate.
- Do not merge this validation PR to `main`.
- Do not enable auto-merge.

## Required release validation
1. Build the exact candidate source as a Raspberry Pi image.
2. Record and verify the generated SHA-256 checksum/artifact identity.
3. Use only this newest successfully built checksum-verified image for normal QEMU validation.
4. Use the exact same verified image for ARM64-QEMU validation.
5. Require repeated stable green normal + ARM64 system tests before calling the candidate flash-ready.
6. Physical Raspberry Pi testing remains the final hardware acceptance step before stable designation.

## Feature exclusions
Work still in separate Draft PRs, including OTA control-plane/device notification expansion and unrelated CI/policy improvements, is not pulled into this release candidate merely because it exists.
